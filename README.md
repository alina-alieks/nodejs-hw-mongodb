The Phonebook app is a backend application for managing a collection of contacts, where you can use HTTP requests to retrieve data for all contacts or a single one by ID. It also includes logic for adding new contacts, deleting, and editing existing ones.

Pagination, sorting by name, filtering for the contacts collection, and input validation have been implemented. 

Authentication and authorization are also included.

A password reset functionality using tokens has been implemented, and the Brevo service is used for sending email notifications.

Image uploads are integrated using the Cloudinary service. 

Documentation has been created using Swagger: [https://phonebook-app-kqpj.onrender.com/api-docs/]
